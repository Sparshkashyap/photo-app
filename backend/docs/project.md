# Project Definition

## Project Name

Google Photos Clone Backend

## Goal

Build a minimal photo storage backend using AWS services.

## Core Features

1. Signup
2. Login
3. Upload Photo
4. Download Photo
5. Logout

## Authentication

JWT based authentication.

## Database

DynamoDB.

## Storage

Amazon S3.

## Backend

Node.js + Express.js.

## Compute

AWS Lambda.

## API

API Gateway HTTP API.

## Deployment

AWS SAM.

## Allowed Technologies

- Node.js
- Express.js
- JavaScript
- AWS Lambda
- API Gateway
- DynamoDB
- S3
- JWT
- bcrypt
- AWS SDK v3
- serverless-http
- AWS SAM

## Not Using

- MongoDB
- PostgreSQL
- Redis
- Firebase
- Supabase
- Cognito
- Mongoose
- TypeScript

## Features NOT Included

- Albums
- Likes
- Comments
- Sharing
- Image editing
- AI image analysis
- Search
- Notifications
- Admin dashboard
- Social features
